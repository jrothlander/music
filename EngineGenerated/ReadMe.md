These are generated from a rules engine. No AI involved.

You select a style, which assigns a template that defines the structure, such as INTRO, A, B, BREAK, A, B, SOLO, ENDING.
You select a time signature, key, and a chord progression. From there, the engine sets up the details. Your job is to create the 
riff, the melody, and your solo. All of the base structure is set up for you. You can modify any of it as you see fit, but having
the structure generated just helps you get your structure set up.
