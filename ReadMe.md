This repo contains music that I have created for various games and game assets using either my own Atari POKEY chip emulator, AI assistance, or from scratch. The 8-bit music has been created by me personally and using a custom Windows application an Atari POKEY chip emulator library. I have details about the applications, Atari POKEY chip, and the emulator in a repo here on GitHub: https://github.com/jrothlander/PokeyEmulator 

By AI assistance, I mean that I used AI for things like cleaning this up, creating a beat, creating a run that sounds similar to another run that I liked, etc. Nothing here was actually generated by AI. That is what I mean by AI assistance. I do plan to experiment with AI, and I will create a folder called AI-generated for those.
